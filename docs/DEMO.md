# 五分钟演示脚本

## 场景一：符合条件且窗口开放

选择“华芯精密传动（虚构）”、两个政策、评估日期 2026-08-10。

预期结果：

- 卓越级智能工厂：窗口开放、条件匹配、材料齐全；
- 专精特新“小巨人”：条件匹配，但窗口已经关闭；
- 系统不虚构补助金额；
- 每条判断可展开查看官方依据；
- 系统生成带 `[待补充/核验]` 的申报材料初稿。

## 场景二：明确不符合

选择“远启精密部件（虚构）”。

预期结果：

- 展示规模以上工业企业、获评层级、收入、研发、知识产权等失败项；
- 显示申报草稿和企业档案中的 2025 年营业收入不一致；
- 明确列出缺少的材料。

## 场景三：拒绝猜测

选择“凌云智能装备（虚构，信息不完整）”。

预期结果：

- 对国内领先水平、人工智能场景比例等返回 unknown；
- 总体结果为 needs_information，而不是擅自判断符合或不符合。

## 场景四：权限门禁

生成评估后直接请求导出，analyst 角色得到 403。使用 approver 角色批准后才允许导出；完整过程写入执行轨迹。
